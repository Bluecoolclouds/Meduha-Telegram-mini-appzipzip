# Проверка дешёвой фотогенерации

## Разрешение и границы

Пользователь поручил выбрать небольшой дневной лимит и проверить дешёвое фото.
Проверка ограничена одним платным запросом Z-Image Turbo с предварительной
числовой сметой не выше $0,02. Это ограничение тестового запуска, а не
подтверждение наличия жёсткого финансового потолка у провайдера.

## Настройки production

Через существующий защищённый admin API изменён только дневной лимит
на аккаунт: **0 → 10 кредитов**. Использован согласованный временный
администратор; Telegram-владелец не назначался.

Повторное чтение production подтвердило:

- `spending_enabled=false`;
- общий и канальный дневные лимиты — 500 кредитов;
- лимит аккаунта — 10, максимум активных резервов — 3;
- канал Higgsfield выключен, параллельность — 1;
- все 18 фото-моделей и 75 видео-моделей выключены;
- 9 проверенных фото-тарифов сохранены;
- заданий приложения, резервов и записей кредитного журнала — 0.

Использованный временный административный сеанс завершён: проверка не
обнаружила активных временных сеансов, созданных в интервале этой операции.
Сам способ временного входа не отключён.

## Один реальный запрос к Higgsfield

- Endpoint: `z-image/turbo`.
- Параметры: `resolution=1k`, `aspect_ratio=1:1`, `prompt_extend=false`.
- Содержание: предметное фото банки мёда; без пользовательских данных.
- Свежая числовая смета непосредственно перед отправкой: **$0,015**.
- Платных попыток отправки: **1**, без повторного POST.
- Request ID: `52e4b965-219e-421e-b9df-af0ceefc9904`.
- Статус провайдера: **completed**.
- Результат: одно PNG, **1024 × 1024**, 1 201 871 байт.
- Изображение скачано, проверены сигнатура, размеры и видимое содержимое.

Выходной файл и локальный маркер единственной попытки находятся в
`generated-artifacts/production-photo-smoke-2026-10-27/`.
Каталог исключён из Git и публикации. Результат не публиковался в Community.
Ключи, пароли, cookies и подписанные URL в отчёт не включены.

## Что этот тест не подтверждает

Это прямой тест реальной генерации у провайдера, не пользовательская
генерация через Telegram. Временный администратор не подменялся
Telegram-пользователем. Пользовательские балансы и журнал приложения
не использовались; резервирование, списание и возврат через приложение
этим тестом не проверены.

**$0,015 — смета, а не независимо сверенное окончательное списание.**
Для финансового подтверждения требуется сопоставить существующий request ID
с окончательной записью провайдера или счётом. Новая генерация для такой
сверки не нужна. Токеновые модели остаются заблокированными.
