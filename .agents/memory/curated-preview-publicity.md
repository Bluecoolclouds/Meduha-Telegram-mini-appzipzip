---
name: Curated preview publicity
description: Why only explicitly curated examples can use immutable public preview caching
---

Only explicitly approved starter examples may use public immutable derivative
caching. Community publications must retain fresh publication/access checks
before conditional and range responses; never cache their permission decisions.

**Why:** the user explicitly distinguishes already-public curated examples from
user work that can be withdrawn. Speed must not turn revocable user media into
permanently public assets.

**How to apply:** keep this boundary when changing preview delivery or adding
new example material. An approved example is a deliberate publishing decision,
not a label inferred from a media URL or its current publication status.
